### Button-style Checkbox Groups

The checkbox group supports a button style, where options are arranged as tag-like buttons horizontally or vertically. Selected items are highlighted with an outline or a filled background. Suitable for scenarios with many options that require clear feedback, such as permission assignment or feature toggles.

{{ button }}

### Button-style Checkbox Groups in Different Sizes

Button-style checkbox groups are available in small, medium (default), and large sizes.

{{ button-size }}

### Button-style Checkbox Groups in Different Variants

Button-style checkbox groups support three variants: outline, default-filled (default), and primary-filled, and can be laid out vertically.
