#### 悬浮液态玻璃胶囊标签栏

对标 iOS 26 液态玻璃（Liquid Glass）：在悬浮胶囊形态上叠加 `--glass` 材质，通过 `backdrop-filter` 对胶囊后方内容做模糊与饱和度增强，配合镜面高光与折射描边，呈现通透的玻璃质感。适用于需要强悬浮感与高级质感的底部导航场景。
